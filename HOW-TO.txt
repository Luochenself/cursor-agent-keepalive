cursor-agent-keepalive — 快速用法
================================

作用：
  - Agent 用量墙 → 等约 2 秒 → 自动发一次「继续」
  - Connection / 可重试错误 → 自动点 Resume 或 Try again
  - 不点空输入时同槽位的语音按钮

安装（推荐 · Workbench 注入）：
  1. Node.js ≥ 18
  2. node scripts/install-workbench-inject.mjs
     （写入 Cursor 目录，必要时管理员）
  3. Ctrl+Shift+P → Developer: Reload Window
  4. 右下角绿色 keepalive ON

改脚本后：再跑 install + Reload。
Cursor 大版本更新覆盖 workbench.html 后再装一次。

Console：
  __cursorKeepaliveStatus()
  __cursorKeepalivePing()
  __cursorKeepaliveReset()
  __cursorKeepaliveStop()
